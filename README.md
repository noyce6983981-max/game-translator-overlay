# 游戏翻译器 · 原位中文

Windows 游戏英文 → 简体中文实时翻译工具：在本地识别屏幕文字，将译文覆盖在原文字附近，鼠标可穿透覆盖层继续操作游戏。

## 使用

1. 完整解压 ZIP，保留 `GameTranslator` 文件夹里的全部内容，尤其是 `local` 文件夹。
2. 将游戏设置为窗口化或无边框窗口模式。
3. 运行 **游戏翻译器.exe**，选择游戏窗口与识别区域，然后点击“开始翻译”。

无需另装 Python 或 .NET，也无需填写 API 密钥。支持 Windows 10 2004 及以上的 64 位系统；需要系统具备英语 OCR 识别功能。详细说明见压缩包内的《快速开始.md》。

| 快捷键 | 操作 |
| --- | --- |
| F8 | 开始 / 暂停 |
| F9 | 隐藏 / 显示译文 |
| Ctrl + Alt + F7 | 打开控制台 |

## 翻译方式

默认联网优先，使用 Google 免密钥网页翻译端点。网络需能够访问 Google 翻译；服务超时、限流或失败时自动转用随包提供的本地英中模型。也可以主动选择“本地离线”。网页端点没有可用性保证，专有名词和文学句子的译文需要结合上下文理解。

文字稳定后再翻译，并缓存重复台词。覆盖层采用矩形底色遮盖原文，不能重建原始游戏背景。动画、倾斜文字或艺术字体可能影响识别；不保证固定翻译延迟。

## 隐私与组件

OCR 在本地执行。联网翻译发送选定区域识别出的文字，不上传截图。离线模式不发送翻译请求。程序首次运行会生成个人设置和台词缓存；再次分享时请排除 `data` 文件夹。

发布包包含程序、离线模型、运行组件、源码与第三方许可，不包含个人设置、台词缓存或游戏截图。C# 源码位于 `source`，本地引擎脚本位于 `local/translate_worker.py`；组件作者、来源和许可见 `local/README-DEPENDENCIES.md`、`local/licenses` 以及运行时许可文件。
